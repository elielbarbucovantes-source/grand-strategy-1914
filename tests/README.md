# tests/ — Tests

**Ce dossier est vide volontairement.** Aucun framework ni code de test n'existe encore.

La stratégie est décrite dans [docs/development/testing-strategy.md](../docs/development/testing-strategy.md).

Principes à respecter dès le premier test :

- résultats réels uniquement, jamais inventés ;
- tests déterministes ;
- un bug corrigé ⇒ un test de non-régression ;
- les scénarios de référence du noyau de règles seront versionnés ici ;
- les tests d'IA ne se limitent pas à des tests unitaires : contrat, comportement, évaluation quantitative.

# assets/ — Ressources

**Ce dossier est vide volontairement.** Aucun asset graphique, sonore ou de carte n'a été produit ou intégré.

## Règles

1. **Vérifier la licence** de chaque asset avant intégration (Q-020).
2. Ne jamais importer un asset sans documenter :
   - sa source ;
   - son auteur ;
   - sa licence ;
   - les modifications éventuelles.
3. Ne pas versionner de fichiers lourds sans justification ; utiliser un stockage adapté si nécessaire.
4. Séparer les assets sources des assets exportés.
5. Ne pas utiliser d'œuvre protégée (carte, musique, image) sans autorisation explicite.

Un fichier `CREDITS.md` devra être créé dès le premier asset intégré.

Voir [PROJECT.md § 5](../PROJECT.md#5-inspirations-et-références) et [AGENTS.md § 10](../AGENTS.md#10-dépendances-et-licences).
